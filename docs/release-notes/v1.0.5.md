## MindMaze 1.0.5

An open-source rebuild of **MindMaze**, the castle quiz game from Microsoft Encarta. It runs natively on **Windows, Linux, macOS and Android**.

**Bring your own disc.** These downloads contain no Encarta content. On first start the game reads your own Encarta disc or image and copies the questions, pictures, sounds and music it needs.

### New in 1.0.5
- **RecompLauncher support:** one-click setup from a supported Encarta edition, launcher-managed settings and saves, and direct launch without MindMaze's own setup prompts.
- **Portable launcher setup:** `--prepare`, `--home` and `--disc` can perform first-time extraction without opening a game window and report setup progress.
- **Versioned portable downloads** with the system and processor in every desktop archive name.
- **Windows:** one ZIP containing the portable `MindMaze.exe`; the built-in updater now verifies that ZIP and replaces only the executable.
- **Linux AppImage:** built from the same portable folder as the tarball and tested both normally and unpacked, as launchers use it.
- **Diagnostic logs:** `mindmaze.log` and `mindmaze-prev.log` stay beside the settings and player files, making the two latest runs available for bug reports.
- **Apple build checks:** the universal macOS app is built and signature-checked on a macOS 15 runner, and the mobile app passes an unsigned iOS Simulator build. Neither build has been manually tested on Apple hardware; iOS remains experimental and is not released.
- **recomp.board manifest:** the repository now owns and keeps its recomp.fyi listing current.

Each file has a `<file>.sha256` containing its SHA-256 checksum. MindMaze and RecompLauncher verify downloads before installing them.

### Install
- **Windows:** unzip the Windows package into a folder and start `MindMaze.exe`.
- **Linux:** unpack the tarball and run `MindMaze/MindMaze`, or make the AppImage executable and run it.
- **macOS:** unzip the package, move `MindMaze.app` to Applications, then right-click it and choose **Open** the first time.
- **Android:** open `MindMaze.apk`; Android updates from 1.0.3 and later install over the existing app and keep its data.

MindMaze accepts US English Encarta 95 MPEG, 96 Macintosh, 97, 98 and 2006 Premium editions. The game data is copied locally during setup and the original media is not needed afterwards.
