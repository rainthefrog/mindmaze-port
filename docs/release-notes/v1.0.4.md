## MindMaze 1.0.4

An open-source rebuild of **MindMaze**, the castle quiz game from Microsoft Encarta. It runs natively on **Windows, Linux, macOS and Android**.

**Bring your own disc.** These downloads contain no Encarta content. On first start the game reads your own Encarta disc (or a disc image) and copies the questions, pictures, sounds and music it needs.

### New in 1.0.4
- **Modern options** (Settings > *Modern options*; each can be switched off, and the *Classic MindMaze* switch turns them all off and back on again - also `--classic` / `--modern` on the command line):
  - **Touch layout:** on phones and tablets (landscape) a column with big buttons beside the room holds the players, *Topic* and *Difficulty 1-4*, the answers with their topic icons, and the map at twice the size between the torches; a scoreboard shows every player's rank and score, one award bar shows the way to the next award and to the top, and "1 player" / "Several players" makes a game for several people obvious. The layout fits the screen and uses the widescreen pictures where they fill it better. The original question and speech pop-ups stay.
  - **Continue unfinished games:** the game is saved after every turn; the castle gate offers to continue it.
  - **Hints:** a *50/50* button during a question removes two wrong answers (one if you already tried once); then you have one chance left and the question is worth half its points (key H).
  - **Turn prompts and player stats:** "Your turn" between players, so a phone can be passed around; a *Stats* screen with answers, first-try rate, streaks, mazes and a breakdown per area and level.
  - **Large text and high contrast** for questions, answers and messages.
  - **Animations:** a short walk-in through the castle door, rooms slide in, answers flash green or red, the score counts up, pop-ups fade and slide in, what people say appears line by line, a new rank shines, matches flicker, confetti falls when the castle is won, and everything that can be tapped glints in turn, left to right.
- **Pop-up pages:** a speech or question too long for its scroll gets *Previous* / *Next*, each page filled to its last line; a speech always ends with *Close*, and *Next* while its lines are still appearing shows them all first. No more smaller fonts or cut-off endings.
- **Main Menu** (replaces New Game and Quit Game) returns to the castle gate instead of closing MindMaze; an unfinished game can be continued there or at the next start. (Windows: MindMaze menu > *Exit* closes the program; Linux and macOS: Ctrl+Q / Cmd+Q.)
- **Scores and ranks are saved right away:** after every correct answer and every new rank, and whenever the app goes to the background. Before, the Android app (and a closed browser tab) lost them unless you quit the game from inside first.
- **Settings at any time:** on the castle-gate page, and in the castle (gear button in the room's top right corner; touch layout: *Settings* in the column). Not while a question is open.
- **Mute button** in the top left corner of every screen: music and sounds off and on at once; your volume settings stay, and the choice is remembered.
- **Android:** the keyboard opens for typing a name, with a text box above it; the game pauses in the background (music stops, a question's clock waits); true full screen (no status bar, also on phones with a camera cutout); landscape only; no more crackling music.
- **Encarta 96 for Macintosh now has music:** its QuickTime music is converted to MIDI when the disc is read (the same notes as the Windows discs' music).
- **Rooms:** wall paintings no longer hang behind people or cupboards (they move to the other wall; rooms of a saved game are tidied too), and a person or thing can be tapped anywhere on its picture where nothing else is in the way.
- **Fixes:** text codes in a few questions ("Moli&egrave:re" now Molière, chemical formulas like CH2=CHC≡N, "¾ time"); the red dot sits in the middle of its room on the touch map.

### What's in the game
- The full game: castle rooms, doors, questions, characters, music and sounds, as in Encarta.
- Works with any one of these discs (US English): **Encarta 2006**, **Encarta 98**, **Encarta 97**, **Encarta 95 (MPEG edition)** and **Encarta 96 for Macintosh**.
- **Add questions from your other discs:** Settings > *Add questions from a disc*. Questions already in another source are skipped, so nothing repeats.
- Optional **HD (2x) and widescreen pictures** you can make yourself (see [docs/HD-ART.md](../blob/main/docs/HD-ART.md)). F2 switches HD, F3 the wide view.
- **Command-line options for launchers** (Windows, Linux, macOS): `MindMaze --help` lists them.

### Install on Windows
1. Download `MindMaze.exe` and put it in a folder of its own. It is not signed, so SmartScreen warns once: *More info* > *Run anyway*.
2. Start it. It looks for an inserted or mounted Encarta disc. If there is none, it asks for the disc image (`.iso`), or for `ENCARTA.EXE` (2006) or `MINDMAZE.DB` (95 to 98) on the disc.
3. It copies the game data into a `data` folder next to the exe (or `%LOCALAPPDATA%\MindMaze` if that folder isn't writable), then starts. You don't need the disc after that.

Keys: F2 HD pictures, F3 widescreen, F11 full screen. Updating from 1.0.2 or older: download this exe once and replace the old one; later versions update themselves.

### Install on Linux
1. Download `MindMaze-linux-x86_64.tar.gz` and unpack it: `tar xzf MindMaze-linux-x86_64.tar.gz`. Nothing else needs installing; it is built to run on Ubuntu 22.04 and later and other current x86_64 desktops.
2. Run `MindMaze/MindMaze`. It looks for a mounted Encarta disc (`/media`, `/run/media`, `/mnt`). If there is none, it asks for the disc image, or you can pass it directly: `./MindMaze ~/Downloads/Encarta.iso`.
3. The data goes into the `MindMaze` folder itself (or `~/.local/share/MindMaze` if that folder isn't writable).

Steam Deck: add `MindMaze` as a non-Steam game. The file dialog needs the desktop, so either start it once from Desktop Mode, or pass the disc image as above.

**Alternative:** the Windows exe also runs under Wine (`wine MindMaze.exe`) or Proton.

Updating from 1.0.2 or older: unpack this tarball over the old `MindMaze` folder once; later versions update themselves.

### Install on macOS
1. Download `MindMaze-macos.zip` and unzip it (Safari does this by itself). Move `MindMaze.app` to *Applications* (an app started straight from *Downloads* cannot update itself).
2. The app isn't signed with an Apple developer ID, so macOS blocks the first launch. Right-click `MindMaze.app` > **Open** > **Open**. On macOS 15 and later, open it once, then go to System Settings > Privacy & Security > **Open Anyway**. If macOS says the app "is damaged", run this in Terminal: `xattr -dr com.apple.quarantine MindMaze.app`.
3. Mount your Encarta disc image (double-click the `.iso`) before starting, or choose the image when asked. The data goes to `~/Library/Application Support/MindMaze`.

### Install on Android
1. Download `MindMaze.apk` on the phone and open it. When Android asks, allow installing from your browser or file manager. If 1.0.0–1.0.2 is installed, uninstall it first (those were signed with throwaway keys; from 1.0.3 on, updates install over the app).
2. On first start, import the game data once in any of these ways:
   - **From the Windows, Linux or macOS game:** Settings > *Export data for the phone app* writes one `.zip`, including any HD pictures you made. Put it on the phone and choose *Import a MindMaze data file (.zip)*.
   - **From a disc image on the phone:** choose the `.iso`. The app extracts it itself.
   - **From a link:** paste a link to your disc image or data `.zip`. A disc image is read in pieces, not downloaded whole. The server must allow HTTP range requests and CORS.
3. Optional: Settings > Pictures > *HD pictures: file or link...* installs an HD-art `.zip`.

The app also opens `mindmaze://import?url=<disc image link>&art=<HD pictures zip link>` links, for example from a QR code.

**Note:** from 1.0.3 on, every APK is signed with the same key, so updates install over the app and keep your data. The first update asks you once to allow MindMaze to install apps.
